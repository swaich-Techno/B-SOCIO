# B Socio Website

A dependency-free, statically generated portfolio and studio website for B Socio.

## Source of truth

Edit the templates and behavior in `src/` and the source media in `assets/`. The `dist/` directory is generated by the build, is intentionally ignored by Git, and must not be edited directly.

## Local development

```bash
npm run dev
```

Open `http://localhost:4173`.

## Verify a production build

```bash
npm test
```

The generated site is written to `dist/`. The verification script checks local links and fragments, unique page metadata, social images, sitemap coverage, JSON-LD syntax, heading structure, image dimensions, form labels, safe external links and common accessibility regressions.

## Vercel preview

The included `vercel.json` runs `npm run build`, serves the generated `dist/` directory, enables clean URLs, removes trailing slashes and adds baseline response headers.

1. Run `npm test` locally and commit the source files (not `dist/`) to a non-production branch.
2. Import the repository into Vercel, or connect the existing project to it. Use the repository root, leave the framework preset as `Other`, and keep the configuration from `vercel.json`. No environment variables are required.
3. Push the review branch to create a Vercel preview deployment. Do not use `vercel --prod`.
4. Review the preview at mobile and desktop widths. Exercise every navigation route, the custom 404, both contact actions and the external project links. Inspect the browser console and confirm the configured response headers.
5. Only after the preview is approved, add or confirm `bsocio.in` and `www.bsocio.in` in the Vercel project's Domains settings and choose the preferred primary domain. Change DNS in a separate, explicitly authorized step.

Do not attach the live domains to an unreviewed preview and do not change DNS as part of preview creation.

## Contact behavior

The contact form intentionally opens the visitor's email client or WhatsApp. It does not send data to an unconfigured third-party form provider.
